🧪 虚拟实验室使用说明

专为高一化学设计，涵盖无机物的性质与反应。现象按真实原理模拟（视觉做了夸张，方便观察）。

基本操作

  • 选试剂：在「试剂」页点一种（高亮即选中）。
  • 加入容器：点实验台任意位置 → 该试剂进入容器（可连续加多种）。
  • 发生反应：点「⚡让它们反应！」；需加热/点燃时会提示你。
  • 看结果：台面播放现象（气泡/沉淀/火焰/爆炸），右侧「现象」页给方程式+考点。

🖱️ 台面操作（可拖拽）

  • 选中：点台面上的仪器 → 出现虚线框即为当前容器，之后加的试剂都进它。
  • 移动：按住仪器拖动，松手后会带惯性滑行，仪器之间会互相碰撞推开。
  • 加热：把酒精灯拖到容器旁边 → 自动加热该容器；拖开即停止。
  • 倾倒：把一个容器拖到另一个容器上方 → 液体倒入并尝试反应。
  • 导气：点「🩻连接导管」→ 依次点发生瓶和接收瓶，气体会自动通入并反应（如 Cl₂ 通入 KI-淀粉溶液）。
  • 增删：「仪器」页点仪器即可再放一个；「🗑️移除选中」拿走当前容器。

🔊 本次升级：实验室音效

  • 点右上角 🔊音效 可开关、调音量，还能逐个试听 8 类声音。所有音效都由 Web Audio 实时合成，单文件离线可用，不加载任何外部音频。
  • 💧液体：倒液有湍流水声 + 液面升高的共鸣升调 + 咕嘟气泡；飞溅是宽频水花；玻璃棒搅拌是低沉旋涡声。
  • 🫧气泡：单个气泡是音调上滑 + 破裂 click；碳酸盐加酸、制气反应是持续冒泡声，气泡密度随反应强度变化。
  • 🔥燃烧：点燃「噗」一声，随后是低频火焰呼啸 + 随机噼啪；铁丝火星四射时噼啪明显更密；熄火自动淡出。
  • 🪨固体/玻璃：粉末是沙沙细碎声，块状/金属是「咚」+ 玻璃非谐波泛音的清脆叮；拖动仪器互相碰撞、放下仪器、检验工具靠近瓶口都有敲击声（带节流，不会吵）。
  • 💥爆炸/爆鸣：低频冲击波下扫 + 白噪声爆裂 + 长尾轰鸣 + 碎玻璃回响；冲塞、爆鸣气是短促尖锐的 pop。只有真爆炸才用大音量。
  • 🌫其他：钠在水面游动、白雾、漏气、碘升华是嘶嘶声；塞橡皮塞是摩擦闷响；通电是 50Hz 嗡鸣；沉淀沉降是细沙声；钝化反应刻意保持安静（因为它本来就没有明显现象）。
  • 酸入水 / 水入酸的声音也完全不同：前者是平缓注水 + 搅拌，后者是暴沸 + 大量气泡 + 飞溅 + 警示 pop。

🆕 特效与视觉升级

  • 🥄 固体药品看得见了：加固体时会看到颗粒从瓶口下落堆积，按物质画出粉末堆 / 晶体棱面 / 金属光泽片 / 镁条 / 螺旋铁丝 / 块状大理石等；反应时固体逐渐缩小溶解、炭化变黑膨胀、加热发红热辉光、结晶水合物由蓝变白。
  • 🎭 特效不再「什么都爆炸」：把 29 处滥用爆炸压缩到 5 处真爆炸（爆鸣气、H₂+Cl₂ 光照、NH₄NO₃、NaN₃、F₂ 与水），其余按现象细分出 22 类专属视觉：金属燃烧按元素给不同火焰（Mg 耀眼白光+白烟 / Fe 火星四射 / Na 黄焰）、硫安静蓝紫火焰、磷大量白烟、铝热强光+熔融铁水落下、气体淡蓝火焰、蔗糖炭化黑面包、碘升华紫烟、NH₃+HCl 白烟、结晶水失水、中和放热、钝化「没有现象」等。
  • 🫗 酸入水 ≠ 水入酸：按加料顺序判定，两套完全不同特效。酸入水：沿壁细流 + 玻璃棒搅拌 + 温度计缓升 80~90℃ + 轻微蒸汽，不飞溅；水入酸：局部暴沸 + 30 滴橙色酸液飞溅 + 浓白酸雾 + 危险虚线警示 + 轻震屏。操作页有对比按钮和原理卡。
  • 🏷 现象标签：反应时容器上方浮出「浮·熔·游·响·红」「脱水炭化·炭柱膨胀」「耀眼强光·熔融铁水落下」等标签，画面和文字一一对应。
  • 💧 液面细节：新增弯月面（边缘上翘）、斜向反光、温度计小部件、泡沫层、凝华晶体、升华紫烟、加料浮字。
  • 🔍 搜索支持中文常用名：搜「高锰酸钾 / 纯碱 / 胆矾 / 烧碱 / 双氧水 / 钡餐 / 明矾 / 鬼火」等俗称也能命中，双击结果可直接加入容器。

新增功能

  • 🔎 检验：点工具（带火星木条、石灰水、试纸、磁铁、激光笔…）→ 出现在台面上 → 按住拖到容器口/液体处松手即可检验。
  • 🫗 分离：萃取分液（碘水+CCl₄分层）、过滤、蒸发结晶、蒸馏；还有移液管/容量瓶读数误差与配制一定浓度溶液的步骤和误差分析。
  • 🟤 胶体：Fe(OH)₃胶体制备、丁达尔效应、聚沉、U型管电泳、渗析、豆浆点豆腐。
  • 🧰 装置：拼装「发生→除杂→干燥→收集→尾气」五段制气装置，点「检查装置」看评价。
  • ⚖️ 离子共存：勾选离子和隐含条件，自动找出不能共存的组合并给出离子方程式。
